## Problem

### Printing numbers 10 - 24

Listen

### Task

Write a program to print numbers from $10$ to $24$ in the increments of $2$ on separate lines using a for loop.

 **Output:** 

```
10
12
14
16
18
20
22
24

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-02T08:05:47.329Z  

```c_cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for(int i=10;i<=24;i+=2){
        cout << i << endl;
    }
}

```
