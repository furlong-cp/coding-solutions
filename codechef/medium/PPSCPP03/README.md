## Problem

### Printing text

In the last problem, we saw how to output an integer (using cout).
Now let's see how to output some text.
There is only one difference. All textual content should start and end with double quotes.
For eg -

```
cout << "Hey";

```

### Task
- Replace the _ (underscores) in the editor with the text "I love C++" to output "I love C++".

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-02T18:43:12.062Z  

```c_cpp
#include <iostream>
using namespace std;

int main() {

  cout << "I love C++";  //Replace the _ (underscores) with "I love C++"

  return 0;
}
```
