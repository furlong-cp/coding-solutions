## Problem

### Multiple Outputs

We can use as many cout statements as we want.
Write a program which does the following

- Output: 7
- Output: 3.

 **Note**  - Notice that in the output they are printed together without any space between them.

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-05T15:37:57.882Z  

```c_cpp
#include <iostream>
using namespace std;

int main() {
    cout << 7 << 3;


  
  return 0;
}
```
