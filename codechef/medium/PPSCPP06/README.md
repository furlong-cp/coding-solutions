## Problem

### Outputs In Seperate Lines

We can use " **\n** " to have the next outputs be on the next line.
It is like pressing the "Enter" / "Return" key on your keyboard, but for the output displayed.
Example:

```
cout << 5 + 4 <<  "\n";

```

### Task

Write a program which does the following

- Output: 7
- Output: 3 in a separate line using the given command.

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-05T15:38:51.509Z  

```c_cpp
#include <iostream>
using namespace std;

int main() {

  cout << 7;
  cout << endl ;
  cout << 3;

  return 0;
}

```
